# Design assets and copyright

This repository's **Shree Jewellers Atelier** interface is an original implementation tailored for this jewellery management application.

## Original work
- `src/JewelleryArtwork.tsx`: custom-created geometric gemstone logo and jewellery pendant illustration written as React SVG, with no embedded external images.
- `src/polish.css`: bespoke interface composition, visual tokens, typographic system and responsive styling.
- Original brand copy, layout, section arrangements and UI components in this change.

- Other JavaScript libraries continue to be governed by their own package licenses.
